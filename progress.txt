## Codebase Patterns
- Tailwind v4: CSS-first config (`@import "tailwindcss"`), no tailwind.config.js needed
- PostCSS: only `@tailwindcss/postcss` plugin, no autoprefixer/postcss-import
- next.config.ts: `output: 'standalone'` required for Azure Container Apps
- tsconfig: `moduleResolution: "bundler"`, `jsx: "preserve"`, `strict: true`
- Path alias: `@/*` → `./src/*`
- Drizzle: `drizzle-kit push` for local dev, `DATABASE_PATH` env var with `?? 'local.db'` fallback
- AI SDK: `@openrouter/ai-sdk-provider` for OpenRouter, `@ai-sdk/openai-compatible` for Cerebras
- Cerebras model ID: `zai-glm-4.7` (NOT `glm-4.7`), base URL: `https://api.cerebras.ai/v1`
- AI providers use lazy init pattern (functions, not module-level constants) to avoid build-time env var failures
- ESLint: `next lint` deprecated in Next.js 16, migrate to flat config when upgrading
- SSE parser: shared `parseSSEFrames` in `src/lib/sse-parser.ts` — both useCollect and useSimulate import from here
- Custom animations: Tailwind v4 `@keyframes` at top level + `@utility animate-xxx { animation: ... }` in globals.css
- Fade-out transition: `animation: ... forwards` (fill mode) prevents flash back, use setTimeout matching duration for router.refresh()
- React Strict Mode: mount-triggered effects fire twice in dev — use `useRef` boolean guard for side-effectful API calls
- Markdown rendering: `marked` + `@tailwindcss/typography` (`@plugin` directive in CSS), centralized in `src/lib/markdown.ts`
- File download: client-side Blob API pattern in `src/lib/download.ts` — no server route needed
- Toast: zero-dep hook (`useToast`) + component pattern with enter/exit CSS animations
